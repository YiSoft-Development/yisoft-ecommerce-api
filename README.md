# yisoft-ecommerce-api
eCommerce Repository

# Contexto
<b>yisoft-ecommerce-api</b> es un proyecto el cual está enfocado al desarrollo de un ecommerce que permitirá tener una gestion
de la plataforma a detalle desde un panel de administrador, el cual también incluye una pasarela de pagos.

# Requisitos
<ol>
    <li>Java 25</li>
    <li>Maven</li>
</ol>

# Como compilar
1. Clonar el repositorio
2. Ejecutar ```mvn clean install``` para poder bajar las dependencias al repositorio local.
