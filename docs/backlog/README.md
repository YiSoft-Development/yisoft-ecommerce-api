# Backlog

Cada historia es un archivo dentro de la carpeta de su fase. Se resuelven una por una y cada una se revisa por PR.

## Formato

Toda historia de back incluye, según aplique:

- Historia
- Endpoint o componente
- Caso de uso
- Request
- Validaciones
- Qué debe hacer
- Qué se guarda
- Response
- Errores
- Pruebas esperadas
- Fuera de esta historia
- Criterios de revisión
